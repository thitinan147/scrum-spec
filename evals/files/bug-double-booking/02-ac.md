## 1.1 Requirement & Acceptance Criteria

**Bug**
- Current behavior: pressing "Book" twice quickly creates 2 bookings for the same room and time (repro: pick room A 10:00–11:00, then double-click "Book")
- Correct behavior: one booking is created, and "Book" cannot be pressed again while waiting for the result
- Must not change: booking another room at the same time still works · the message "This room is already booked" shows as before

**Business Rules** (validation, permissions, conditions · grouped by topic)
- The same room and time slot can have only 1 booking

**Out of Scope** (include the AC/EC numbers that were cut)
- Removing double bookings that already exist

**Acceptance Criteria**

| # | Given / When / Then | Verified by |
|---|---|---|
| AC1 | Given the form is complete When "Book" is double-clicked Then 1 new booking is created and the button cannot be pressed again while waiting | Unit + Integration |
| EC1 | Given room A is booked 10:00–11:00 When room B is booked for the same time Then the booking works as before | Integration |
| EC2 | Given the room is already booked When "Book" is pressed Then "This room is already booked" is shown as before | Manual |
