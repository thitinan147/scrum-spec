## 1.1 Requirement & Acceptance Criteria

**Problem → Outcome:** Finding a room in a long list is slow → type a search and see only the matching rooms

**User Flow**
1. Open the booking form
2. Type the room name in the search field
3. Pick a room from the search results

**Business Rules** (validation, permissions, conditions · grouped by topic)
- Search starts after at least 3 characters are typed
- This form is shared with the edit-booking page (D1)

**Out of Scope** (include the AC/EC numbers that were cut)
- Search by room capacity

**Acceptance Criteria**

| # | Given / When / Then | Verified by |
|---|---|---|
| AC1 | Given the booking form is open When "meeting room" is typed Then only rooms whose name contains this term are shown | Manual |
| AC2 | Given "A" is typed When waiting for the result Then room A is shown | Manual |
| EC1 | Given a term that matches no room is typed When waiting for the result Then "No rooms found" is shown | Manual |
