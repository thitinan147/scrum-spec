## 1.1 Requirement & Acceptance Criteria

**Problem → Outcome:** Staff need admin to book rooms for them → staff book free rooms themselves, and the system prevents double bookings

**User Flow**
1. Staff open the "Book a meeting room" page
2. Pick the date, start time, end time and a free room
3. Attach the meeting agenda (if any)
4. Press "Book" and see the booking in the "My bookings" list

**Business Rules** (validation, permissions, conditions · grouped by topic)
- **Permissions**
  - Only admin can book the large meeting room, in both FE (the room is not shown to others) and BE (responds 403)
- **Form**
  - Required: date, start time, end time, room
  - The end time must be after the start time and on the same day (D2)
  - Times are shown in 24-hour format (D3)
  - Meeting agenda: PDF up to 10 MB (D5)

**Out of Scope** (include the AC/EC numbers that were cut)
- Editing and cancelling a booking (RB-13)
- Email notifications

**Acceptance Criteria**

| # | Given / When / Then | Verified by |
|---|---|---|
| AC1 | Given staff open the booking page When they pick a date, time and a free room Then the "Book" button is enabled | Unit + Manual |
| AC2 | Given the form is complete When "Book" is pressed Then the new booking shows in the "My bookings" list | Integration + Manual |
| AC3 | Given no room is picked yet When looking at the "Book" button Then the button is disabled | Unit |
| AC4 | Given a PDF agenda up to 10 MB is attached When it is uploaded Then the file name and size are shown | Manual |
| EC1 | Given the user is not admin When they open the room list Then they do not see the large meeting room | Manual |
| EC2 | Given a file over 10 MB is attached When it is uploaded Then an error shows under the field and the "Book" button is disabled | Unit + Manual |
| EC3 | Given the room is already booked in that time slot When "Book" is pressed Then the message "This room is already booked" shows and no double booking is created | Integration |

**Open Questions**

| Question | Ask (PO / BE / UX / QA / Team) | Proposed assumption to use for now |
|---|---|---|
| Can a booking span two days? | PO | No (D2) |
| Are agenda file types other than PDF supported? | PO | Accept PDF only |
